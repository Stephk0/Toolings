## At a glance

The 3ds Max Editable Poly **Constraints** for Blender, as a toggle. Switch it on in the Edit-mode header, pick **Edge**, **Face** or **Normal**, and every transform is kept on the mesh. That covers `G` / `R` / `S` in any keymap, the toolbar gizmos, Mesh ▸ Transform and F9. Rotate a cube's loop cut with Edge on: the loop shears across the cube and the cube stays a cube.

## Install

<Steps>
1. Download `EdgeConstraintMode_v2.1.0.zip`.
2. **Edit → Preferences → Add-ons → Install from Disk**.
3. Enable it. The constraint toggle and the **Edge / Face / Normal** dropdown appear in the 3D View header in Edit Mode, right after the UV menu.
</Steps>

## Day-to-day vs Advanced

<Tabs>
<TabItem label="Day-to-day">

1. Enter Edit Mode, switch the constraint **on** and pick **Edge**, **Face** or **Normal**.
2. Transform as usual: keys, gizmos, menus, typed values, axis locks. The constraint follows live while you drag.
3. Switch it **off** for plain Blender transforms. Right-click the toggle → **Assign Shortcut** to bind it (Max uses `Shift+X`).

</TabItem>
<TabItem label="Advanced">

### How it works

1. Blender's own transform computes where each selected vertex *would* go.
2. **Edge:** the motion picks the connected edge (leading out of the selection) it is most aligned with, and the vertex moves by the part of the motion along that edge. It can carry on onto the next edge if the path stays roughly straight, but it stops at sharp corners.
3. **Face:** the vertex goes to the closest point on the original surface.
4. **Normal:** the motion is projected onto the vertex normal.

Pivot follows Blender's Transform Pivot Point setting. **Reach** limits how many edges or face rings a vertex can cross, and **Stop at Selected** stops it at another selected vertex.

</TabItem>
</Tabs>

## Troubleshooting

<Aside type="note" title="What is left unconstrained">
Transforms run by other add-ons' Python scripts, extrude / duplicate macros, and edge or vertex slide (G G).
</Aside>

<Aside type="tip" title="A vertex doesn't move">
The drag is at right angles to every edge the vertex could slide along, so there's nothing to keep. Drag along an edge, or lock an axis that runs along the edges.
</Aside>
