## At a glance

The 3ds Max Editable Poly **Constraints** dropdown for Blender. Pick **Edge**, **Face** or **Normal** in the Edit-mode header and every **G / R / S** keeps the selection on the mesh. Rotate a cube's loop cut with Edge on: the loop shears across the cube and the cube stays a cube.

## Install

<Steps>
1. Download `EdgeConstraintMode_v2.0.0.zip`.
2. **Edit → Preferences → Add-ons → Install from Disk**.
3. Enable it. The **None / Edge / Face / Normal** buttons appear in the 3D View header in Edit Mode.
</Steps>

## Day-to-day vs Advanced

<Tabs>
<TabItem label="Day-to-day">

1. Enter Edit Mode and click **Edge** (or Face / Normal) in the header.
2. Select and press `G`, `R` or `S`.
3. `X` / `Y` / `Z` lock an axis (press again for Local, `Shift` for a plane), type a number for an exact value, hold `Ctrl` to snap.
4. Click **None** to get Blender's own G / R / S back.

</TabItem>
<TabItem label="Advanced">

### How the solver works

1. The transform computes where each selected vertex *would* go with no constraint.
2. **Edge:** the motion picks the connected edge it is most aligned with, and the vertex moves by the part of the motion along that edge. It can carry on onto the next edge if the path stays roughly straight, but it stops at sharp corners. Edges that cross the selection are preferred over the selection's own edges.
3. **Face:** the vertex goes to the closest point on the faces around it.
4. **Normal:** the motion is projected onto the vertex normal.

Pivot follows Blender's Transform Pivot Point setting. **Reach** limits how many edges or face rings a vertex can cross, and **Stop at Selected** stops it at another selected vertex.

</TabItem>
</Tabs>

## Troubleshooting

<Aside type="caution" title="Gizmos and menus are unconstrained">
Only the G / R / S keys use the constraint. The toolbar Move / Rotate / Scale gizmos and Mesh ▸ Transform still run Blender's free transform.
</Aside>

<Aside type="tip" title="A vertex doesn't move">
The drag is at right angles to every edge the vertex could slide along, so there's nothing to keep. Drag along an edge, or lock an axis that runs along the edges.
</Aside>
