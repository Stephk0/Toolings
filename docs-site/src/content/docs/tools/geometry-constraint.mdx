<Aside type="note" title="Formerly Edge Constraint Mode">

</Aside>

The 3ds Max Editable Poly **Constraints** for Blender, as a toggle. Switch it on in the Edit-mode header, pick **Edge**, **Face** or **Normal**, and every transform is kept on the mesh. That covers `G` / `R` / `S` in any keymap, the toolbar gizmos, Mesh ▸ Transform and F9. Rotate a cube's loop cut with Edge on: the loop shears across the cube and the cube stays a cube.

## Install

<Steps>
1. Download `GeometryConstraint_v3.1.0.zip`.
2. **Edit → Preferences → Add-ons → Install from Disk**.
3. Enable it. The constraint toggle and the **Edge / Face / Normal** dropdown appear in the 3D View header in Edit Mode, right after the UV menu.
</Steps>

## Day-to-day vs Advanced

<Tabs>
<TabItem label="Day-to-day">

1. Enter Edit Mode, switch the constraint **on** and pick **Edge**, **Face** or **Normal**.
2. Transform as usual: keys, gizmos, menus, typed values, axis locks. The constraint follows live while you drag.
3. Switch it **off** for plain Blender transforms. Right-click the toggle → **Assign Shortcut** to bind it (Max uses `Shift+X`).

</TabItem>
<TabItem label="Advanced">

### How it works

1. Blender's own transform computes where each selected vertex *would* go.
2. **Edge:** the motion picks the connected edge (leading out of the selection) it is most aligned with, and the vertex moves by the part of the motion along that edge. It can carry on onto the next edge if the path stays roughly straight, but it stops at sharp corners.
3. **Face:** the vertex goes to the closest point on the original surface.
4. **Normal:** the motion is projected onto the vertex normal.

Pivot follows Blender's Transform Pivot Point setting. In Edge mode, **Even Slide** (on by default) moves a connected selection as one piece, every vertex the same distance along its own edge, like Edge Slide. **Show Constraint** draws the rails, surface or normals while you drag. In Edge mode, **Stop at Vertices** (on by default) stops a vertex at the end of its own edge, so a loop never slides through another loop. Turn it off and **Reach** limits how many edges a vertex can cross, and **Stop at Selected** stops it at another selected vertex. In Face mode, **Reach** is the number of face rings.

</TabItem>
</Tabs>

## Troubleshooting

<Aside type="note" title="What is left unconstrained">
Transforms run by other add-ons' Python scripts, extrude / duplicate macros, and edge or vertex slide (G G).
</Aside>

<Aside type="tip" title="A vertex doesn't move">
The drag is at right angles to every edge the vertex could slide along, so there's nothing to keep. Drag along an edge, or lock an axis that runs along the edges.
</Aside>

## Changelog

- **v3.1.0**: fixes broken shading after rotate / scale and stale geometry on back-to-back drags. New Even Slide (moves keep the selection's size, like Edge Slide) and Show Constraint overlay.
- **v3.0.0**: renamed from Edge Constraint Mode to Geometry Constraint (new extension id; uninstall the old add-on first). No behaviour change.
- **v2.2.0**: first working release. Loops stop at existing loops (Stop at Vertices); two selected edges or loops scale and rotate along the edges between them.
- **v2.1.0** (non-functional): Live mode. The toggle now constrains Blender's own transforms (any keymap, gizmos, menus, F9); undo keeps the result. Fixes for round loops (Edge) and moved patches (Face).
- **v2.0.0** (non-functional): None / Edge / Face / Normal constraints, Max-style rotate and scale (loop shear keeps a cube a cube), axis locks, numeric input, snapping, pivot modes, redo.
- **v1.1.2** (non-functional): restores built-in gizmos hidden by 1.1.0 / 1.1.1.
- **v1.1.0** (non-functional): persistent toggle and solver.
- **v1.0.x** (non-functional): initial releases.
