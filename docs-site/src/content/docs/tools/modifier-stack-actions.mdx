## At a glance

Right-click any modifier in the Properties editor. Below Blender's own entries you get **Show Up To Here** (hide everything after it, restorable), **Extract Up To Here** / **As...** (new mesh object from the stack at that point), **Add Modifier Before / After** (Blender's own Add Modifier menu, asset catalogs included, inserting next to the clicked modifier), **Copy / Paste Before / After** and **Move Up / Down / to First / to Last**.

## Install

<Steps>
1. Download `ModifierStackActions_v1.1.0.zip`.
2. **Edit → Preferences → Add-ons → Install from Disk**, or drag the zip into Blender.
3. Enable **Modifier Stack Actions**. Right-click any modifier panel to use it.
</Steps>

## Day-to-day vs Advanced

<Tabs>
<TabItem label="Day-to-day">

1. **Show Up To Here** on a modifier hides everything after it in the viewport. A red banner in the Modifiers panel shows where the preview stops. **Restore** on the banner, or the same right-click again, brings the stack back.
2. **Extract Up To Here** creates `<Object>_<Modifier>`: a plain mesh with everything up to and including that modifier applied. **As...** asks for the name first. The source stays untouched.
3. **Add Modifier Before / After** opens the normal Add Modifier menu. Type to search. The pick lands next to the clicked modifier.
4. **Copy Modifier**, then **Paste Before / After** on any modifier (any object) puts a copy with all its settings right there.
5. **Move Up / Down** shifts the modifier one slot; **Move to First / Last** sends it to the top or bottom.

### Details

- Show Up To Here only touches the viewport toggle, and only on modifiers that were visible. Restore matches by name, and the preview is saved in the .blend.
- Extract briefly switches the later modifiers off, evaluates, copies the mesh and switches them back. A disabled modifier before the clicked one stays off; the clicked one is always applied. Works on Mesh, Curve, Surface and Text, also in Edit Mode.
- Add Before / After: Blender always adds new modifiers at the end, so the add-on moves the new one into place right after it appears. This also works for Geometry Nodes assets. Undo is two steps (move, then add).
- Everything except Add Before / After is in F3 search and then acts on the active modifier.

## Troubleshooting

<Aside type="tip" title="The entries don't appear">
Right-click on a modifier panel in the Properties editor. Right-clicks in the 3D viewport or the Outliner don't show them.
</Aside>

<Aside type="note" title="A new modifier landed at the end">
The Before / After slot only applies to the next modifier added from that submenu. If the stack changed in another way first, the new modifier goes to the end as usual.
</Aside>
