# Changelog — Smart Wireframe View

## 1.0.0 — 2026-10-20

- First release. Port of the ST3E 3ds Max WireframeEdgeFaceOff macros: one
  hotkey cycles Overlays Off → Overlays → Overlays + Wireframe.
- Shift+Alt+Z forward (replaces Toggle Overlays), Ctrl+Shift+Alt+Z backward.
- Preferences: choose which states are in the cycle; apply to all 3D
  Viewports.
